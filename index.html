Tidy up your folder, gently.

Point it at a folder and it sorts every loose file into subfolders by type — .png → /png, .pdf → /pdf. Everything happens inside your browser's sandbox. Nothing is read by, sent to, or stored on any server.

Scoped permission
Access is granted only to the exact folder you pick, never your whole disk.
Collision-safe writes
A same-named file at the destination gets renamed with a suffix, never overwritten.
Revert two ways
Undo instantly in-session, or keep a manifest to revert even after closing the tab.

Built on the File System Access API — supported in desktop Chrome, Edge, and Opera. Not available in Firefox ,Safari and brave, and support on Android Chrome is inconsistent, so desktop is recommended. Only files at the top level of the chosen folder are touched; existing subfolders are left alone.

This physically moves files on disk. Collision-safe writes and revert options reduce risk, but they're not a replacement for a backup. If the folder matters, keep one elsewhere before running large sorts.
